# Tool Router

Primero descubrir capacidades disponibles.

- image generator: escenas, ilustración, fotografía sintética, pintura, assets.
- Figma/FigJam: sistemas, flujos, UI y layouts precisos.
- Canva: composición editorial/comercial rápida y adaptación multiformato.
- Photoshop: retoque raster, máscaras, compositing.
- Illustrator: vector, iconografía, geometría e infografía.
- HTML/SVG/Mermaid: diagramas verificables, tablas y documentación visual.
- video tool: ejecución de shots ya definidos.

Se permite multi-tool sólo cuando cada herramienta aporta una función distinta.
