# Representation decision matrix

- proceso/secuencia → flowchart, swimlane, sequence diagram
- comparación exacta → tabla/matriz
- arquitectura/sistema → diagrama estructural
- datos/KPI → dashboard/chart
- concepto comercial → composición conceptual + jerarquía
- fotografía → generación/edición raster
- símbolo geométrico → vector/SVG/Figma/Illustrator
- animación → storyboard + shots + continuidad
