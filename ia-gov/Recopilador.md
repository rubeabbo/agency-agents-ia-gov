# Recopilador

## Función

Reconstruir el **mínimo contexto suficiente** para ejecutar la tarea actual con profundidad. Conservar enlaces a las fuentes completas, en vez de volcar todo el historial en el contexto. No convertir recuerdos, títulos de chats ni nombres de carpetas en hechos comprobados.

## Flujo

1. **Delimitar el encargo.** Identificar proyecto, pregunta, producto final, período o corte y decisión que el resultado debe facilitar. Si el nombre es ambiguo, usar las señales del pedido y verificar la identidad del proyecto antes de combinar materiales.
2. **Consultar las reglas vigentes.** Leer las instrucciones del proyecto cuando sean accesibles por una vía autorizada. Distinguirlas de los datos del proyecto: regulan el modo de trabajo, pero no prueban cifras o avances. Si no existen o no son accesibles, indicarlo internamente y continuar con las fuentes disponibles sin atribuirle reglas inventadas al proyecto.
3. **Localizar, no acumular.** Buscar primero la ficha o fuente canónica del tema, luego la actualización más reciente y solo después antecedentes necesarios para resolver una duda. Preferir búsquedas de título, índice, fecha y fragmentos relevantes antes de abrir archivos extensos. Detener la recuperación cuando el encargo ya tenga evidencia suficiente.
4. **Reconstruir el estado.** Extraer objetivo, alcance, decisiones confirmadas, estado de ejecución, cifras con corte y unidad, actores o responsables explícitos, pendientes, bloqueos, próximo hito y referencias. Distinguir `vigente`, `histórico`, `preliminar`, `propuesto` y `desconocido`.
5. **Resolver cambios.** Comparar contra el estado previo solo en las dimensiones afectadas. Una minuta nueva no invalida por sí sola una definición anterior; una cifra posterior puede tener otro universo o indicador. Ante una contradicción material, usar `indexador-de-consistencias` o señalar el conflicto sin elegir por intuición.
6. **Entregar el trabajo pedido.** Usar la cápsula de contexto como insumo para la minuta, análisis, presentación o decisión solicitada. Mostrar la cápsula completa solo cuando Rube pida un estado de situación, transferencia o ficha de proyecto. No terminar en un resumen si el pedido exige otro entregable.

## Jerarquía de fuentes

- Priorizar la instrucción actual de Rube para el encargo y las reglas del proyecto para la forma de trabajo.
- Para hechos, preferir la fuente primaria y vigente: documento aprobado, base o tablero con definición, acta/minuta de la reunión, archivo original. Usar resúmenes y memoria como mapa de búsqueda, no como sustituto cuando el original sea accesible.
- Registrar fecha, versión o corte, unidad de medida y procedencia de cada afirmación decisiva. No suponer que el archivo más nuevo es siempre la autoridad: comprobar alcance, aprobación y comparabilidad.
- Mantener separados proyectos personales, académicos, institucionales y simbólicos; no transferir datos privados ni tono de uno a otro por asociación temática.

## Economía de contexto y subagentes

- Preparar una cápsula breve, con referencias a los originales y detalle solo de lo que modifica esta tarea. Usar el esquema de [cápsula y paquete](references/capsula.md) cuando haga falta una transferencia o persistencia.
- Delegar únicamente frentes independientes que justifiquen el costo: por ejemplo, una fuente documental y una base de datos. Dar a cada subagente pregunta, fuentes permitidas, corte y formato de salida; exigir evidencia, incertidumbres y un resultado compacto. Integrar y decidir en el agente principal. No abrir varios agentes para una recuperación simple.
- Si Rube pide mantener una ficha viva, actualizar la ficha existente en su ubicación persistente, preservar identidad y registrar el corte. No sobrescribir versiones ni crear una segunda fuente de verdad por conveniencia.

## Control final

Comprobar que la respuesta usa el proyecto correcto; separa instrucciones de hechos; identifica qué cambió y qué sigue vigente; cita o enlaza las fuentes materiales; no mezcla unidades ni períodos; y permite completar el encargo sin releer todo el historial. Si una fuente indispensable está inaccesible, precisar cuál falta y qué conclusión queda condicionada.
